# Maintainers

## Maintainer Role

The current maintainer owns the project direction, release process, issue triage, and pull request review.

## Maintenance Responsibilities

- Review issues and pull requests for Windows audio compatibility.
- Keep installation and troubleshooting documentation current.
- Maintain dependency compatibility for `faster-whisper`, `pyaudiowpatch`, `CustomTkinter`, and translation providers.
- Package and publish Windows release artifacts when the build is stable enough for end users.
- Track security-sensitive areas such as transcript handling, external translation providers, and local configuration files.

## OpenAI Codex for Open Source Use

Potential Codex/API-credit workflows for this repository:

- Review pull requests for audio-device edge cases and GUI regressions.
- Triage bug reports by extracting environment details and suggesting reproduction steps.
- Generate tests for provider payload construction and configuration migration.
- Draft release notes from merged pull requests.
